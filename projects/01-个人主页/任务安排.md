# 第一周任务安排：个人作品集主页

节奏：每天 1-2 小时。学一个点 → 马上用进项目 → 当天提交推送。不要攒到周末一起做。

## 第 1 天：HTML 骨架（今天）

- 学：HTML 基础标签（h1~h6、p、a、img、ul/li、section、header、footer）
- 做：把 `index.html` 里的 TODO 全部补上（自我介绍、项目占位等）
- 提交：双击仓库根目录的「提交推送.bat」，或手动运行 git 三条命令
- 验收：双击 index.html 能在浏览器打开，结构完整

## 第 2 天：CSS 基础 + Flex

- 学：CSS 选择器、盒模型、颜色、Flex 布局
- 做：把头部和导航做漂亮，技能区改成列表样式
- 提交一次

## 第 3 天：Grid + 响应式

- 学：Grid 布局、媒体查询 `@media`
- 做：技能和项目做成卡片网格，手机一行 1 个、电脑一行 3 个
- 提交一次

## 第 4 天：动效 + 细节

- 学：`hover`、`transition`、简单 `animation`
- 做：卡片和链接加 hover 效果，整体调好看
- 提交一次

## 第 5 天：自测 + 收尾

- 手机和电脑各打开一遍，检查不破版
- 更新项目 README，写清页面内容
- 提交一次
- 把仓库地址记下来，阶段 4 写简历用：`https://github.com/cnmwsy/LCH-portfolio`

## 卡住了怎么办

- 先自己搜（关键词：CSS 是什么 / flex 布局教程）
- 实在不会就截图发我，我帮你拆解，但代码尽量自己敲
