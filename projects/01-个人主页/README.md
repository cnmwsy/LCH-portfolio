# 项目 1：个人作品集主页

求职简历的落地页——HR 或面试官点开你的 GitHub 仓库，第一眼看到的就是这个页面。

## 技术点（对应岗位要求）

- HTML5 语义化标签（header / nav / main / section / footer）
- CSS3：Flex 布局、Grid 布局、响应式（媒体查询）、动画
- 简单性能与兼容性意识（标签规范、视口设置）

## 验收标准

- [ ] 手机和电脑上都能正常打开，不破版
- [ ] 包含四个板块：个人介绍、技能、项目、联系方式
- [ ] 导航链接能跳转到对应板块
- [ ] 页面无报错、样式完整
- [ ] 学习期间每天至少 commit 一次

## 怎么打开

直接双击 `index.html` 用浏览器打开即可。这是纯静态页面，不需要启动任何服务。
